# v331 — 목록에서 빠진 이유 표시 · 22-3 16 해설 시간 초과

## 1. «22-3 17 이 안 보임» — 왜 빠졌는지 바로 보이게
- 목록 줄(윗줄)에서 문항을 빼는 거르기가 여러 겹이라 어느 것에 걸렸는지 알 수 없었음
  - 연도·회차·찾기 / 등급(금·은·동·똥) / 체크 − · 맞힘 − (같은 문제끼리 같이 셈) / 회차外 − / 중복 묶기(동일 −·유사 −) / 랜덤 개수
- 미니맵: 지금 목록에 없는 칸은 «점선 테두리» · 마우스를 올리면 «⛔ 지금 목록에 없음 — 이유» 가 나옴
  - 예: «체크 − 1 — 1번 이상 푼 문항은 뺌 · 이 문항 0번 (같은 문제 24-3 17 2번)»
  - 예: «등급 거르기(금·은·동)에 안 맞음 — 이 문항은 똥»
- 미니맵에서 그 칸을 눌러 열면 같은 이유를 알림으로 띄움 · 윗줄 점선 칸에도 같은 이유
- 이유를 보고 그 거르기를 끄면 목록에 다시 나옴

## 2. 22-3 16 상세 Opus — 오래 걸리고 «원칙 미달» 창
- 원인: (1)① (1)② (2)③ … 처럼 소문항 안에 ①② 가 또 있는 문제
  - 모델은 잎(①~⑥)을 세어 소문항 6개라 하고, 워커는 (1)(2)(3) 만 세어 «3개만» → 원칙 미달로 판정
  - 그래서 Opus 이어서 → 풀이만 → 풀이만 → Sonnet 까지 네 번 불러 시간 초과·요금 낭비
- 고침
  - 소문항 셈: (n) 만 · ①② 만 · (n)① 짝 셋 중 가장 많은 값으로
  - 단계 수가 충분하면 이름표 모자람은 «보충» 으로만 (다시 부르지 않음)
  - 시간 한도 줄임: 다시 받기 2분 30초 · 작은 틀 4분 · Sonnet 대체 4분 30초까지만 → 한 문항 5분 안쪽
