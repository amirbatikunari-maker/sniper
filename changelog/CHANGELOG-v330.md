## 3. 식이 «C바» 처럼 읽는 말로 나오던 것
- 원인: 해설 규칙에 «글 칸에서는 부정을 'C 바' 처럼 글로 쓴다» 가 있었음 → 삭제
- 새 규칙: 쉽게 말하면 · 먼저 알아야 할 것 · 주어진 값 · 왜 · 검산 · 흔한 실수 등 글 칸에서도 식·기호는 $…$ KaTeX
- 이미 저장된 해설 / 모델이 또 어겨도 화면에서 바꿔 그림
  - C바 · C 바 → $\overline{C}$ · (A+B)바 → $\overline{A+B}$ · BC바 → $B\overline{C}$
  - 맨 글자 논리식 S = ABC + D · A+B · A·B → 수식으로
  - 안 건드림: AND·OR·NAND·KEC·MC·THR 같은 약어 / 숫자·단위 섞인 것(380V = 220V) / I = P/V / «A 바로 옆»
- review · explain-batch 화면도 같은 방식
