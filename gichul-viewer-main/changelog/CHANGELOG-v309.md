# v309 — 비전공자용 해설 · 최소 답안

## 추가
- **쉽게 말하면**(easy): 모든 유형 해설 맨 위에 비전공자용 비유 설명 3~5문장
  - 순서: 묻는 것 → 생활 비유 → 풀이 흐름 한 줄
- **최소 답안 — 이만큼은 꼭**(min_ans): 단답·서술·나열형 전용
  - 소문항마다 "이만큼만 써도 만점"인 가장 짧은 답
  - 필수 핵심어는 형광펜 + `★ 필수:` 줄로 따로 표시
  - 모델이 형광펜을 빠뜨려도 필수어 첫 자리를 자동으로 칠함
- 단계 누락 방지 규칙 강화: 단위 환산·상전압 변환·표 찾기·반올림도 단계로 적음, why는 "하는 일 → 왜 → 어떻게" 순서

## 검사
- 단답·서술·나열형에 min_ans가 아예 없으면 → 필수 미달(다시 받음)
- easy 없음 · min_ans 소문항 수 부족 · must 빔 → 보충(작은 틀로 한 번 채움)
